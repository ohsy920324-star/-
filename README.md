# 강의록 → 강의자료 정리기

강의 스크립트를 붙여넣으면 Claude가 **5색 박스 형식의 강의자료**로 정리하고,
**Word(.docx)** 파일로 다운로드해 주는 정적 웹사이트입니다. 서버가 필요 없습니다.

## 형식 규칙

- 강의 내용을 **하나도 빠짐없이, 강의 진행 순서(타임라인)대로** 정리
- 마케팅 용어는 전부 쉽게 풀어서 설명
- 숫자·사례·멘트는 절대 축약하지 않음
- 맨 앞에 **목차(페이지 번호 포함)**
- 5가지 색깔 박스(글자 라벨)
  - `[용어]` 용어 설명 (초록)
  - `[사장님께 이렇게 말하세요]` 광고주 설명 멘트 (노랑)
  - `[바로 쓰는 실전 멘트]` 카톡 복붙 스크립트 (분홍)
  - `[핵심]` 핵심 포인트 (파랑)
  - `[주의]` 실수 주의사항 (주황)

## 사용 방법

1. `index.html`을 브라우저에서 엽니다. (또는 GitHub Pages 등 정적 호스팅에 배포)
2. **Claude API 키**를 입력합니다. (키는 브라우저에만 저장되고 Anthropic API로만 전송됩니다)
   - 키 발급: <https://console.anthropic.com/>
3. 모델을 선택합니다. (기본: Opus 4.8 — 최고 품질)
4. 강의 스크립트를 붙여넣고 **‘강의자료로 정리하기’**를 누릅니다.
5. 오른쪽 미리보기를 확인한 뒤 **‘Word(.docx) 다운로드’**를 누릅니다.

### 목차 페이지 번호

다운로드한 .docx의 목차 페이지 번호는, Word에서 파일을 연 뒤
**목차를 우클릭 → 필드 업데이트**(또는 전체 선택 후 `F9`)를 하면 자동으로 채워집니다.
(워드의 목차 필드는 문서를 실제로 페이지로 나눌 때 번호가 계산되기 때문입니다.)

## 기술 메모

- 프런트엔드만으로 동작하는 정적 사이트(HTML/CSS/JS).
- 브라우저에서 Claude Messages API를 직접 호출
  (`anthropic-dangerous-direct-browser-access` 헤더 + 스트리밍).
- 결과를 안정적으로 받기 위해 **structured outputs**(JSON 스키마)로 응답을 강제.
- [docx](https://github.com/dolanmiu/docx) 라이브러리(UMD, CDN)로 클라이언트에서 .docx 생성.

## 배포 (선택)

GitHub Pages로 무료 배포하려면, 이 저장소의 Settings → Pages에서
브랜치를 지정해 정적 사이트로 게시하면 됩니다. 별도 빌드가 필요 없습니다.
