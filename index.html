강의록 → 강의자료 정리기

스크립트를 하나씩 추가하면 누적되고, 섹션이 끝나면 완성본 한 개(.docx)로 받습니다.

1. 설정 (섹션 시작 시 한 번)

2. 스크립트 추가 (이 단계를 반복)

3. 정리된 조각 0

  • 아직 추가된 조각이 없습니다.

전체 미리보기 (누적 결과)

정리 결과가 여기에 이어붙어 표시됩니다.

박스 종류 / 목차 페이지번호 안내
  • [용어] 마케팅 용어 쉬운 풀이 (초록)
  • [사장님께 이렇게 말하세요] 광고주 설명 멘트 (노랑)
  • [바로 쓰는 실전 멘트] 카톡 복붙 스크립트·사례 원문 (분홍)
  • [핵심] 핵심 포인트 (파랑)
  • [주의] 실수 주의사항 (주황)

다운로드한 .docx의 목차 페이지 번호는 Word에서 열어 목차를 우클릭 → 필드 업데이트(또는 전체 선택 후 F9) 하면 자동으로 채워집니다.
